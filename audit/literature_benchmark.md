# Primary literature benchmark for the mentor manuscript

Updated 2026-09-29. The exposition comparison below uses versions first public **before 1 November 2024**. Later publications in the manuscript bibliography are current scientific context, not models for this writing audit.

| Earlier paper | What its explanation makes explicit | Decision for this manuscript |
|---|---|---|
| [CaloFlow, 2021](https://arxiv.org/abs/2106.05285) | Separates the generative map from physics observables and a classifier comparison. | Explain sampled readout separately from incident energy; report distributional screening rather than infer fidelity from the loss. |
| [ALICE neutron ZDC study, 2023](https://arxiv.org/abs/2306.13606v1) | Names the detector segmentation, input particle attributes, zero-response handling and exact output representation. | State the 6,790-channel raw-deposit target and distinguish it from that study's photon/fiber representation. |
| [CaloDiffusion, 2023](https://arxiv.org/abs/2308.03876) | Explains how geometry adaptation changes the representation before presenting results. | Define the ganged-centroid geometry and the project graph before treating components as observables. |
| [HEP generative-metric study, 2022/2023](https://arxiv.org/abs/2211.10295) | States that no single goodness-of-fit test has power against all alternatives; separates interpretable projections from multivariate tests and discusses classifier limitations. | Give each diagnostic a definition and failure mode; preserve the failed C2ST gate while stating its pair-split limitation. |
| [CaloGraph, February 2024](https://arxiv.org/abs/2402.11575v1) | Specifies node coordinates, edge construction, preprocessing, architecture, hyperparameters and observable-level results. | Supply channel/layer counts, the directed-edge recipe, stage dimensions, equations and observable definitions; do not equate the graph with a physical-neighbor standard. |
| [CaloDREAM v1, May 2024](https://arxiv.org/abs/2405.09629v1) | Defines dataset energy range and threshold, then factorizes layer energies and cell shapes before giving the flow objective and sampling method. | Present input/target semantics, layer budgets, support, cell shares, teacher forcing and numerical solver in sampling order. |
| [ALICE ZDC diffusion study, June 2024](https://arxiv.org/abs/2406.03233v1) | Compares a detector-specific alternative with baselines and discusses quality/time tradeoffs. | Do not claim a speed advantage without a comparable end-to-end timing measurement. |
| [CaloChallenge v1, October 2024](https://arxiv.org/abs/2410.21611v1) | Uses complementary shower-quality metrics alongside model size and generation time across several datasets and model families. | Report the available response, support, classifier and numerical checks, and state plainly which broader comparisons are unavailable. |

The papers above are precedents for explanation and evaluation design, not evidence about this checkpoint. In particular, [CaloGraph](https://arxiv.org/abs/2402.11575v1) uses a different graph and detector, and [ALICE ZDC](https://arxiv.org/abs/2306.13606v1) uses a different output representation. Their numerical results cannot rank this raw-deposit model.

The manuscript also cites later work for scientific context: [the 2025 CaloChallenge journal article](https://doi.org/10.1088/1361-6633/ae1304), [a published ALICE ZDC flow-matching study](https://doi.org/10.1016/j.cpc.2025.109936), [ExpertSim](https://arxiv.org/abs/2508.20991), [the 2025 ALICE ZDC comparison](https://doi.org/10.1007/s41781-025-00130-x), and [the 2026 fixed-input ALICE co-activation study](https://arxiv.org/abs/2608.12795). These are not pre-November-2024 exposition sources. None establishes this checkpoint's fidelity, graph robustness, detector identity, physical threshold, simulation configuration or speed.
